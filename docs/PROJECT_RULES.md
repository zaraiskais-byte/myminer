# Rules of Work -- Caesar CZR

## Rule 1 -- Single Source
The single source of truth is the official GitHub repository.

## Rule 2 -- Single Integration
Wallet node chain mining pool and interfaces in the same project.

## Rule 3 -- Single Test
Build and full tests before any push.

## Rule 4 -- No Deletion
No deletion of old versions.
No modification of wallet or chain data before verified integration.

## Rule 5 -- Languages
Conversation with the owner in beautiful Arabic.
Termux blocks in correct English only.
No commas no parentheses no special characters in Termux blocks.

## Rule 6 -- Real Ports
RPC default 8443.
P2P default 18555.
When Android app is installed and conflicts use 38543 and 39555 in Termux.

## Rule 7 -- No Claim Before Proof
No feature is described as working before real on device test.
Results are announced only when seen with evidence.
