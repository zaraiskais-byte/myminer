# CZR Monetary Policy V1

Status: DRAFT

This document is a protocol specification draft.

Final monetary parameters MUST NOT be considered approved until they are:

1. reviewed,
2. implemented,
3. tested,
4. documented consistently,
5. subjected to security review,
6. approved through the Caesar protocol upgrade process.

The network must enforce the declared issuance policy.

Unauthorized issuance MUST be rejected.

Economic policy changes MUST NOT be silently introduced through operational software.
