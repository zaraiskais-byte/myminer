# Caesar CZR Economics

This directory defines the economic policy of the Caesar network.

The economic layer is separate from application marketing and investment claims.

The policy MUST define:

- maximum supply
- issuance rules
- block reward
- reward schedule
- transaction fee rules
- fee treatment
- economic invariants
- allocation policy
- launch policy
- governance and upgrade rules

No economic parameter should be changed silently.

Any parameter affecting consensus, issuance, coinbase, or supply requires a protocol change process and regression testing.

CZR does not provide a guaranteed return.

Network utility, adoption, security, liquidity, regulation, and market conditions can materially affect the economic outcome of the project.
